# projeto-gitops

Plataforma GitOps no Azure construída como projeto de laboratório e portfólio: Terraform, AKS, ArgoCD e pipelines com segurança embutida.

## Repositórios

| Repositório | Responsabilidade |
| --- | --- |
| [azure-gitops-infra](https://github.com/HigorHenrique4tech/azure-gitops-infra) | Terraform: state remoto, rede, ACR, Key Vault, AKS e bootstrap do ArgoCD |
| [azure-gitops-app](https://github.com/HigorHenrique4tech/azure-gitops-app) | Aplicação de exemplo e CI de containers (build, scan, assinatura) |
| [azure-gitops-config](https://github.com/HigorHenrique4tech/azure-gitops-config) | Manifests Kustomize sincronizados pelo ArgoCD |
